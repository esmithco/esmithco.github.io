Features — A Series in Numbers

A whole time series can be crushed into a handful of numbers (features). Compute the same numbers for many series → compare them, group them, and spot the odd ones.
A feature = one number that summarizes the series
meanmedianminmaxsdacf1pacf1trend_strengthseasonal_strengthspikinessstabilityn_crossing_points

One row of numbers per series. That's the whole idea — turn a curve into coordinates.

The Python library — tsfeatures
from tsfeatures import tsfeatures # the Python analog of R's feasts::features # df in long form: columns unique_id · ds (date) · y (value) feats = tsfeatures(df, freq=12) # freq = seasonal period (12 = monthly)
  • tsfeaturesfunction — takes the long df, returns a DataFrame DataFrame: one row per series (unique_id), one column per feature.
  • piecesIt's a bundle of smaller feature functions you can call alone: acf_features, pacf_features, stl_features, entropy… pass a list to compute only what you want.
# only the STL features (trend & seasonal strength, etc.) from tsfeatures import stl_features feats = tsfeatures(df, freq=12, features=[stl_features])
ACF vs PACF — the one you kept mixing up
total memory vs direct memory
ACF(k) = corr(yt, yt−k).
The total link at lag k — including what leaks through the middle lags (t−1 … t−k+1).
PACF(k) = the same correlation after removing lags 1…k−1.
The direct link at exactly lag k. = the coefficient of yt−k when you regress yt on all shorter lags.
  • trendACF decays slowly (everything is correlated); PACF has one spike at lag 1, then ~0.
  • seasonalboth spike at the seasonal lag (12, 24…). A big ACF and PACF there = a real, repeating season.
  • (later)AR(p): PACF cuts off after lag p · MA(q): ACF cuts off after lag q → this is how you read a series for ARIMA (ch. 9).
Trend & seasonal strength  ·  the features that matter most

Straight from the STL split (ch. 3): if pulling out a component leaves little variance in the remainder, that component was strong. Both land in [0, 1].

FT = max (0,  1 − Var(R) / Var(T + R))trend strength — near 1 = strongly trended
FS = max (0,  1 − Var(R) / Var(S + R))seasonal strength — near 1 = strongly seasonal
The feature scatterplot  ·  the "versus" plot

Compute features for every series, then plot one feature against another — each dot is a whole series.

each dot = a series · high on both axes = the season repeats strongly (e.g. every year)
read it — a dot high on both seasonal-ACF and seasonal-PACF = a series whose season is real and strong (last year predicts this year). Corner clusters = groups that need the same model; a lone dot = an outlier series to handle apart. This is exactly how you segment many series before modeling.
✦ Features turn each series into a row of numbers. ACF = total memory, PACF = direct memory. FT, FS ∈ [0,1] say how strong trend / season are. Scatter features across series → find groups & outliers.
