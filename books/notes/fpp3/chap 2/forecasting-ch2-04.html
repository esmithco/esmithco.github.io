Matplotlib + Seaborn — The Main Picture

matplotlib is the plotting engine; seaborn is a higher-level statistical layer built on top of it. The whole game is Figure, Axes, and who draws on them.
The map — who is what
object module alias function method
python ├── matplotlib module │ └── pyplot module · the interface → import ... as plt │ └── seaborn module → import ... as sns └── draws using matplotlib underneath
  • pltalias for pyplot — a convenient interface. Not a class. Functions live on it: plt.plot() plt.subplots() plt.show() plt.savefig().
  • snsalias for seaborn. Not a class. Its functions: sns.lineplot() sns.scatterplot() sns.histplot().
The two objects that matter
Figure — the whole canvas / container └── Axes — one plotting area inside it ├── the plot (lines · points · bars) ├── x-axis · y-axis ├── title └── labels one Figure can hold many Axes: Figure ├─ Axes ├─ Axes └─ Axes
Axes ≠ axis
object  Axes
a whole plotting area.
an axis is just one edge — the x-axis or y-axis that an Axes contains.
The workhorse — plt.subplots()
fig, ax = plt.subplots() │ │ │ └── Axes object — the plotting area └──────── Figure object — the canvas ax.plot(x, y) → draw on THIS Axes
The plot lives on the Axes; the Axes lives inside the Figure. plt.subplots() → Figure + Axes in one line.
The thing you keep mixing up — plt vs ax
implicit interface vs explicit object
plt plt.plot(x, y)
pyplot draws on the current / active Axes.
ax ax.plot(x, y)
draw explicitly on this Axes.
plt.title() ↔ ax.set_title() plt.xlabel() ↔ ax.set_xlabel()
Seaborn sits on top
DATA (DataFrame) ↓ seaborn high-level ↓ matplotlib Axes + Figure
  • on its ownsns.scatterplot(data=df, x="age", y="salary") is valid alone — seaborn creates/uses the Figure & Axes for you. No plt.subplots() needed.
  • on my AxesPass ax=ax to target a specific Axes (next section).
fig, ax = plt.subplots() sns.lineplot(data=df, x="date", y="sales", ax=ax) ↑ draw on THIS matplotlib Axes
You → seaborn → matplotlib Axes → Figure. Seaborn doesn't replace matplotlib — it's a higher layer on top of it.
seaborn (level) vs matplotlib (control)
seaborn
high-level · statistical · DataFrame-native · auto Figure/Axes · quick charts.
matplotlib
the engine · direct Figure/Axes control · limits, layout, annotations, saving.
Know only seaborn → most common charts, but not every matplotlib operation.
show · save · close — be precise
  • plt.show()displays the Figures pyplot is currently managing / open — not just the current one. note — "current Figure" and "all managed Figures" are different ideas.
  • plt.close(fig)removes a Figure from pyplot's management.
  • fig.savefig()fig.savefig("f.png") saves exactly this Figure — all its Axes as one canvas.
  • plt.savefig()saves the current / active Figure. note — not "save every Figure".
one Figure vs many Figures
One Figure, many Axes
Figure ├ Axes ├ Axes └ Axes
subplots in one canvas · fig.savefig() saves them together.
Several Figures
Fig1→Axes · Fig2→Axes · Fig3→Axes
separate canvases · plt.show() can show all managed · fig1.savefig() saves only Figure 1.
