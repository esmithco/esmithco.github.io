Pandas — The Main Tool

pandas is a Python module — a library, not a class. It holds classes (constructors that build objects) and functions. Learn its structure and the syntax stops being confusing.
The structure
pandas ├── DataFrame → class · 2-D table (rows × columns) ├── Series → class · 1-D column ├── Timestamp → class · a point in time ├── Period → class · an interval of time ├── DatetimeIndex → class · many points ├── PeriodIndex → class · many intervals └── to_datetime() → function · converts to datetime
  • builddf = pd.DataFrame(...) calls the constructor → builds a DataFrame object. Classes aka constructors. Check with type(df).
  • columndf["age"] selects one column → returns a Series (1-D). pandas builds and returns it for you.
  • .attrdf.columns, df.index are attributes (no ()). df.head(), df.tail() are methods (call with ()).
Three ways to reach data
  • [ ]Depends on what's inside: df["c"] one column · df[["a","b"]] many · df[mask] filter rows.
  • .locBy label (and boolean masks): df.loc[rows, cols]. Picks rows and columns, and can assign.
  • .ilocBy position: df.iloc[0] → the first row.
Filter vs. transform — and how to keep it
Filter — df[df["age"]>25]
"Which rows do I keep?"
Transform — df["age"].apply(f)
"What do I compute per value?"
Neither one changes df. An operation only produces a result — the = stores it:
df["age"] = df["age"].apply(lambda x: x*2)
Transform toolkit
  • applydf["c"].apply(f) → f gets each value. df.apply(f, axis=1) → f gets each row (when you need several columns). axis=0 columns · axis=1 rows
  • mapdf["city"].map({"Cali":"CAL"}) → maps each value → value.
  • vectorPrefer it: df["price"]*df["qty"], (df["a"]>1)&(df["b"]==0), np.where(cond, A, B). Faster and simpler than apply.
