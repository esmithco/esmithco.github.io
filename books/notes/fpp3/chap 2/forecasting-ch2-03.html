1 · Set rent = 5000 where Temp > 50 and cost < 6000
df.loc[(df["Temp"] > 50) & (df["cost"] < 6000), "rent"] = 5000
  • 1df["Temp"] > 50 and df["cost"] < 6000 each build a boolean Series (True / False per row).
  • 2Combine them with & (element-wise AND). Wrap each condition in ( ) — & binds tighter than >.
  • 3df.loc[mask, "rent"] = 5000 selects those rows and the rent column, then writes 5000 — creating rent if it doesn't exist yet.
watch — use & and | (not and / or) for Series, always with parentheses. And boolean assignment goes through .loc, never plain df[...] = .
2 · Flag each row: 50 if cost < 50, else 0
# per value — the lambda gets one value x df["flag"] = df["cost"].apply(lambda x: 50 if x < 50 else 0) # per row — when the rule needs several columns df["flag"] = df.apply(lambda row: 50 if row["cost"] < 50 else 0, axis=1) # vectorized — prefer this when you can df["flag"] = np.where(df["cost"] < 50, 50, 0)
watch — .apply on a Series gives the function each value (x), so row["cost"] wouldn't exist there. To read whole rows use df.apply(..., axis=1).
The pattern — operation → produces a result · = → stores it in df · reach for the simplest tool that works (vectorized > apply).
