# Book Notes

This folder contains a small reading library published with GitHub Pages.

## Add a new note

1. Save an HTML note in `notes/`. Use a short filename such as `forecasting-ch2.html`.
2. In Terminal, run:

   ```bash
   cd "/Users/esmith/Desktop/Files/Projects/book-notes"
   ./publish.sh "Add forecasting chapter 2"
   ```

The command rebuilds the home page, commits the new note, and pushes it to GitHub Pages. The website normally updates within a minute or two.

## Reading notes

- Open the home page to choose a note.
- Within a note, scroll vertically like a PDF/document.
- Use the arrow buttons, keyboard left/right arrows, or swipe left/right on a phone to move to the next note.
